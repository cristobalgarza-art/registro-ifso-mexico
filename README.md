# Registro IFSO México

App web para que los centros bariátricos de México capturen paciente por paciente y el Colegio genere el reporte IFSO.

- `index.html` — la app (una sola página, se instala como app en el celular).
- `config.js` — conexión a la base de datos (Supabase).
- `supabase/schema.sql` — esquema y reglas de seguridad de la base de datos.
